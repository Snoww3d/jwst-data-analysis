## Problem

Python has token validation but no login, registration or refresh, blocking the
lockout parity and admin unlock work in #1186.

## Who it affects

Maintainers completing ADR 0001 and existing Mongo users migrating from .NET.

## What "done" looks like

- [ ] Existing passwords and JWT contracts work in Python.
- [ ] Register/login/refresh return safe DTOs, with Docker failure-case tests.
- [ ] Existing lockout fields survive; #1186 can build on this login path.
- [ ] Implementation PR receives human danger approval and merges before closure.

## Out of scope

#1186 lockout counters/admin endpoints; email flows; frontend changes; production
cutover; gateway removal. This dispatch explicitly stops at an unmerged PR.

## Constraints

Keep .NET Mongo documents, bcrypt hashes and token contracts compatible. Keep
production protections in place. No schema migration, main push or merge.

## Proposed direction (non-binding)

Extend the existing Python auth package and add a users repository.

## Open questions

None blocking implementation; human danger approval remains a merge prerequisite.
